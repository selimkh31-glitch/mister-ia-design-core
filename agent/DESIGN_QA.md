# Design QA Gate

Score each category 0–2.

- 0 = broken / generic / inconsistent
- 1 = acceptable but unresolved
- 2 = deliberate and production-ready

## Categories

1. Brand distinctiveness
2. Information hierarchy
3. Typography system
4. Spacing consistency
5. Color and contrast
6. Component consistency
7. Mobile composition
8. Interaction clarity
9. Motion restraint and purpose
10. Accessibility
11. Image/art direction
12. Anti-generic compliance

Minimum release score: **20/24** with no zero in accessibility, mobile composition or brand distinctiveness.

Any intentional exception should be written into `/design/design.md` so future agents do not "fix" it back into a generic default.
