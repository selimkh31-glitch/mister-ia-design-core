# Artisan Project DNA

## Default strategic bias
- Materiality, craft and detail.
- Project photography carries more weight than icon grids.
- Texture and typography can communicate value better than decoration.
- Avoid construction-template clichés unless the brand intentionally embraces them.

## Good directions
- architectural editorial;
- heritage craftsmanship;
- modern workshop;
- premium restoration;
- rugged utilitarian.

Pick one. Do not blend all five.
