# Project Design QA

## Identity
- [ ] This project is visually distinguishable from other Mister IA projects.
- [ ] Signature devices appear consistently but not repetitively.
- [ ] No generic AI/SaaS motif has been introduced without justification.

## Hierarchy
- [ ] Primary action is obvious.
- [ ] Heading hierarchy is coherent.
- [ ] Dense sections have clear scan paths.

## System
- [ ] Colors use semantic tokens.
- [ ] Spacing uses the approved scale.
- [ ] Radius and shadows use approved values.
- [ ] Component variants are documented when new.

## Responsive
- [ ] 320–390px widths are intentionally composed.
- [ ] Tablet is reviewed, not assumed.
- [ ] Desktop line lengths remain controlled.

## Accessibility
- [ ] Focus is visible.
- [ ] Interactive targets are practical on touch.
- [ ] Contrast is sufficient.
- [ ] Motion respects reduced-motion preference.
- [ ] Semantics and labels remain meaningful.

## Final anti-generic question
Would a screenshot of this interface be plausibly interchangeable with an unrelated startup template?

- [ ] No.
